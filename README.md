# 📄 Generador de Carátulas de Folio - Municipalidad Distrital de Chinchao

Aplicación web desarrollada para la gestión, personalización, impresión y exportación de carátulas de folios y currículums, diseñada para optimizar los procesos de la administración pública.

## 🚀 Características Principales
- **Gestión de Folios:** Creación, edición, duplicado y organización de folios por bloques y periodos.
- **Personalización Visual:** Ajustes avanzados de tipografías, tamaños, escudos, orden y márgenes de la carátula.
- **Búsqueda Inteligente:** Filtros rápidos por número de folio, bloque, periodo o nombres.
- **Control de Duplicados:** Alerta y seguimiento de nombres repetidos entre registros.
- **Impresión Optimizada:** Vista previa y distribución de dos carátulas por página (formato A4) listas para impresión física o PDF.
- **Exportación a Excel:** Generación de reportes detallados y estructurados mediante ExcelJS.
- **Sincronización en la Nube:** Integración con **Supabase** para almacenamiento seguro y persistencia de datos.

## 🛠️ Tecnologías Utilizadas
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla).
- **Librerías & CDN:** 
  - `@supabase/supabase-js` (Base de datos y autenticación).
  - `xlsx` y `exceljs` (Generación de hojas de cálculo).
- **Versionamiento:** Git & GitHub.
